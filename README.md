# KrishiNetra 🌾

KrishiNetra is an AI-powered agricultural market and net-earning advisor designed to help farmers make better decisions about selling their produce.

The project is currently **under development**. It aims to help farmers explore market prices, assess crop quality, discover potential buyers, compare offers, and estimate net earnings after considering relevant costs.

## Features

- Agricultural market and price information
- Net-earning calculation
- Crop quality assessment
- Buyer discovery and offer comparison
- AI-assisted agricultural advice
- Farmer and FPO management
- Trade and transaction tracking

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express, TypeScript
- **Database:** Supabase

## Project Structure

- `frontend/` – Frontend application
- `backend/` – Backend API and business logic

## Status

🚧 This project is under active development. Features and functionality may change as development progresses.
